# CasimirBot server test source preview

This MIT-licensed, source-only preview contains **1,389 selected TypeScript test files** from private source commit `0bc3c8fe23f24e8f5b72d4a40140b7b16a2146e3`. The [base inventory](SOURCE_SELECTION.json) pins 1,368 selected blobs byte-for-byte. A [four-file addendum](SOURCE_ADDENDUM_SESSION_URL_REPAIR.json) records the only transformed files: six copies of one scholarly URL had their unverified `jsessionid` value replaced with the explicit `synthetic-session-id` test fixture. The surrounding source and test assertions are preserved. A [17-file Helix Ask addendum](SOURCE_ADDENDUM_HELIX_ASK_HELD17.json) pins newly reviewed tests byte-for-byte to the same private source. These tests were previously held by a broad auth/account/session path-name filter, not by a credential finding in their source. Other held account/auth paths and the prior scanner-flagged paths remain excluded.

The tests import omitted first-party modules and external packages and are **not a standalone or passing suite**. The owner confirmed MIT rights to first-party source; external packages and referenced material keep their own terms. The linked scholarly article is a reference, not bundled article content or a grant over it. File selection and bounded secret scans cannot establish live auth safety, product acceptance, or physical proof. See [dependency and fixture notes](THIRD_PARTY_NOTICES.md). The historical platform repository remains private.
